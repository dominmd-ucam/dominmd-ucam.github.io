Coloca aquí los modelos originales `.glb` exportados desde Blender (sin comprimir).
Nombres reconocidos ahora mismo: `station-web.glb`, `station-bot.glb`, `station-plugin.glb`, `station-cli.glb`.
`npm run models:optimize` los comprime a `public/models/` (núcleo, va a Pages).
`npm run models:optimize -- --hq` genera `assets-hq/` (texturas 4K) para subir a tu servidor.
